# 🎫 couponmoa-coupon

## 📌 개요

`couponmoa-coupon` 서버는 **쿠폰 발급, 사용, 구독 등 쿠폰과 관련된 모든 기능을 담당하는 서비스**입니다.  
쿠폰 생성부터 사용자 쿠폰 발급, 만료, 사용 처리까지 전 주기를 관리합니다.

---

## 📂 주요 기능

### 🔧 쿠폰 관리 (관리자용)

| 기능 | 설명 |
|------|------|
| 쿠폰 생성 | 관리자가 새로운 쿠폰 생성 |
| 쿠폰 수정 | 쿠폰 정보 수정 |
| 쿠폰 삭제 | 쿠폰 삭제 |
| 쿠폰 조회 | 키워드, 발급 수량 기반 쿠폰 목록 조회 |
| 가게별 쿠폰 목록 조회 | 특정 가게에서 생성한 쿠폰 목록 조회 |

---

### 🧾 사용자 쿠폰 기능

| 기능 | 설명 |
|------|------|
| 쿠폰 발급 (Sync) | 동기 방식으로 쿠폰을 즉시 발급 |
| 쿠폰 발급 (Async) | 비동기 방식으로 요청만 등록하고 빠르게 응답 |
| 발급한 쿠폰 목록 조회 | 사용자 본인의 발급 쿠폰 목록 조회 (페이징 지원) |
| 쿠폰 코드 확인 | 발급된 쿠폰의 고유 코드 확인 |
| 쿠폰 사용 | 사용자 쿠폰을 사용하는 기능 (관리자 권한) |
| 만료 알림 트리거 | 매일 자정 API로 호출되어 만료 예정 쿠폰 사용자에게 알림 전송 |

---

## ⚙️ 기술 스택 및 특징

- **비동기 처리**
- **SQS 기반 비동기 쿠폰 발급**
- **Redis + Lua Script로 동시성 제어**
- **만료 쿠폰 알림 스케줄링 트리거**
